# Penjelasan Singkat Repository
Repository ini dibuat sebagai penyelesaian tugas Pemrograman Dasar TLS26 yang terdiri dari:

Problem 1 (The Last Astronaut) menyimulasikan eliminasi astronot dalam posisi melingkar menggunakan konsep Josephus Problem. Sistem menentukan posisi tereliminasi lewat operasi matematika sisa bagi (modulus) untuk menangani putaran array. Nilai langkah hitungan (K) disesuaikan secara dinamis berdasarkan ID astronot yang keluar—bertambah jika genap dan berkurang jika ganjil—hingga akhirnya tersisa satu astronot sebagai pemenang. Penyelesaian problem 1 dibuat dalam bentuk pseudocode, C++, dan penjelasan logika.

Problem 2 (Alien In The Middle) menerapkan sistem sandi teks dengan menggeser nilai abjad suatu huruf berdasarkan nilai abjad huruf di sebelah kirinya. Huruf pertama disimpan secara utuh tanpa perubahan, sedangkan huruf berikutnya dikonversi ke skala angka 1 hingga 26 lalu dijumlahkan. Perhitungan memanfaatkan operasi modulo 26 agar pergeseran karakter yang melewati huruf Z dapat otomatis berputar kembali ke awal abjad (huruf A). Penyelesaian problem 2 dibuat dalam bentuk flowchart (menggunakan Mermaid Live Editor), C++, dan penjelasan logika.
